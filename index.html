    03 / KNOW THE BOUNDARY

    A focused prototype, with explicit limits.

    What it does

    Follows LotResult → LotTender → TenderingParty → Organization references. Preserves consortium members, reports missing IDs and ambiguous duplicates, excludes subcontractors, and exports JSON.

    What is checked

    Reference traversal is checked against the official SDK 1.16 maximal award example and synthetic edge cases. This is not full XSD or Schematron validation, and has no general production compatibility claim.

    What is outside scope

    Live tender feeds, legacy TED formats, all SDK versions, legal award verification, continuous maintenance, or hosted data storage. Group-of-lots references are shown without expanding group membership.

    AI-assisted development. Independent prototype; no EU/TED affiliation or endorsement. Source code is available under MIT. The illustrative sample is original synthetic data, not a real procurement notice.
